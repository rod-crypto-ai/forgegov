# ForgeGov v0.4 — Connected Workspace Rewrite

This release begins the full application rewrite and replaces the generic read-only feature shell with a connected workspace system.

## Included

- Unified workspace page for API-backed modules
- Live search and record counts
- Table and board views
- CSV export
- Connected create-record modal for pursuits, tasks, saved searches, contacts, teaming requests, agencies, and vendors
- Real POST requests to Django REST endpoints
- Improved empty, loading, and backend error states
- Responsive mobile forms, boards, metrics, and toolbars
- Existing SAM.gov opportunity explorer, dashboard, reports, AI workspace, Django models, REST endpoints, Docker configuration, and PostgreSQL support retained

## Important

This is a working product increment, not a claim that all planned ForgeGov capabilities are finished. Live state/local aggregation, Grants.gov ingestion, production AI, billing, document parsing, and advanced permissions remain future work.
