# ForgeGov v3.1.1 — Private Beta Stabilization & Feedback

## Highlights
- Public pre-login landing page for ForgeGov.
- Test registration opened by default for the beta deployment and switchable at runtime by the Creator.
- Secure Creator / Platform Owner role with the complete Platform Administration control plane.
- `promote_creator` management command requires an existing MFA-enabled user; it is not an authentication bypass.
- In-app beta feedback capture and Platform Admin feedback queue.
- Runtime registration modes: public, private beta, invite only, closed.
- Existing security, governance, connector resilience, and launch-gate controls retained.
