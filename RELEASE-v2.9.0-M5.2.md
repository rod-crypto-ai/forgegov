# ForgeGov v2.9.0-M5.2 — Workspace & Dashboard UX

## Opportunity workspace
- Opportunities now open on Overview by default.
- Overview is the first tab in the horizontal workspace rail.
- ForgeGov AI is the second tab.
- Existing workspace capabilities remain available in the single-row scrolling navigation.

## Dashboard
- ForgeAI Workspace Signals, Upcoming Work, and Recent Activity use aligned fixed-height desktop cards.
- Each dashboard card displays a maximum of four records at a time.
- Overflow remains available through internal scrolling instead of stretching the dashboard vertically.
- Empty states no longer force the dashboard cards to consume the full viewport.
- Tablet and mobile height behavior is constrained separately.

## Baseline
Built on ForgeGov v2.9.0-M5.1.

## Migration
None.
