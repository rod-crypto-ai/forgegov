# ForgeGov v0.8 Complete Rebuild

This package replaces the current ForgeGov source while preserving your `.git` folder and `.env`.

## Install on macOS

1. Extract the ZIP.
2. Open the extracted `forgegov-v0.8` folder.
3. Double-click `INSTALL.command`.
4. If macOS blocks it, right-click `INSTALL.command` and choose **Open**.
5. When the install finishes, open `http://localhost:3000`.

The installer creates a timestamped backup of your existing repository before replacing files.
