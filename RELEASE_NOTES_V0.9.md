# ForgeGov v0.9 — Grants.gov Integration

- Live Grants.gov search2 connection.
- Live fetchOpportunity detail backend endpoint.
- Keyword, agency, opportunity number, ALN/CFDA, funding category, eligibility, funding instrument, and status filters.
- Previous/next pagination across all matching results.
- Saved Grants.gov searches.
- Grants persist into the unified Opportunity database.
- Add grants directly to the pipeline.
- CSV export.
- No Grants.gov API key required.
