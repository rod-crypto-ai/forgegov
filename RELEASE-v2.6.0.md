# ForgeGov v2.6.0 — Experience and Workflow

This release modernizes the everyday ForgeGov experience without changing the database schema.

## Highlights
- Refined responsive visual system for desktop, tablet, and mobile.
- Clean icon-rail behavior for the collapsible sidebar.
- More readable ForgeGov AI conversation layout.
- Local conversation continuity, copy controls, source disclosure, and keyboard-friendly sending.
- Drag-and-drop pursuit Kanban with immediate stage persistence.
- Improved cards, command center surfaces, empty states, focus treatments, and reduced-motion support.

## Deployment
- Rebuild frontend and backend images.
- No new migration is required.
- Run Django tests, ESLint, TypeScript validation, and the Next.js production build before release.
