# ForgeGov v2.0 — Release 4: Intelligence & UX

## Included
- Forecast center upgraded to an activity-style intelligence feed with status context and in-ForgeGov review.
- Contract vehicle cards now open a ForgeGov intelligence panel with holder, agency, value, dates, and source actions.
- Federal award rows now open an award intelligence panel and connect directly to company profiles.
- Existing ForgeGov alerts are promoted into a top-bar notification center with unread counts and automatic refresh.
- Responsive UX styles added for intelligence panels, forecast feeds, mobile layouts, and interactive records.
- Existing Milestones 1–3 features retained.

## Validation
- Python sources compiled with `compileall`.
- Frontend source was checked for route/component consistency. Run the Docker production build locally before deployment.
